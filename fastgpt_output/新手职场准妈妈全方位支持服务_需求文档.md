# 新手职场准妈妈全方位支持服务 - 需求文档

## 📋 项目概述

### 项目名称
新手职场准妈妈全方位支持服务系统

### 项目背景
一位居住在龙岗区的职场准妈妈即将临产,作为新手妈妈缺乏经验,需要全方位的专业指导和支持。涉及孕期知识、产后护理、职场权益、心理支持、就医资源、生活服务等6个专业领域的复杂需求。

### 核心目标
通过多智能体协同服务,为新手职场准妈妈提供专业、全面、个性化的支持,帮助她顺利度过孕期到产后的关键时期。

## 🤖 智能体设计

### 1. 意图识别Agent

**功能**: 分析用户输入,识别需求类别并输出编号(1-6)

**输入**: 用户自然语言问题
**输出**: 数字编号(1-6)

**意图类别**:
1. **孕期知识科普** - 临产征兆、待产包、分娩流程、产检等
2. **产后护理指导** - 新生儿护理、母乳喂养、产后恢复等
3. **职场权益咨询** - 产假、哺乳假、生育保险、职场权益等
4. **情绪心理支持** - 焦虑、抑郁、压力、情绪调节等
5. **就医资源对接** - 龙岗区医院、产科医生、预约挂号等
6. **生活服务协调** - 月子中心、月嫂、家政、产后康复等

**特点**:
- 低温度(0.3)确保稳定输出
- 只输出数字编号,不直接回复用户
- 简洁的prompt提高识别准确率

**服务风格**:
- 专业权威(基于循证医学)
- 温暖关怀(亲切的语气)
- 通俗易懂(专业术语转化)
- 实用导向(可操作建议)

**Temperature**: 0.7 (平衡专业性和亲和力)

### 节点配置

| 节点ID | 节点类型 | 功能说明 |
|--------|----------|----------|
| workflowStart | workflowStart | 工作流开始,接收用户输入 |

| conditionRouter | ifElseNode | 条件路由,分发到专业Agent |
| prenatalAgent | chatNode | 孕期知识科普 |

| workplaceAgent | chatNode | 职场权益咨询 |
| psychologicalAgent | chatNode | 情绪心理支持 |
| medicalAgent | chatNode | 就医资源对接 |
| lifeServiceAgent | chatNode | 生活服务协调 |

### 变量引用规范

使用数组格式进行变量引用:
```json
"value": ["workflowStart", "userChatInput"]
```

### 条件判断配置

使用`includes`运算符匹配意图编号:
```json
{
  "variable": ["intentRecognition", "answerText"],
  "condition": "includes",
  "value": "1"
}
```

### 边(Edges)配置

每条边包含:
- `id`: 边的唯一标识
- `source`: 源节点ID
- `target`: 目标节点ID
- `sourceHandle`: 源节点输出点格式: `{nodeId}-source-{position}`
- `targetHandle`: 目标节点输入点格式: `{nodeId}-target-left`
- `type`: "default"
